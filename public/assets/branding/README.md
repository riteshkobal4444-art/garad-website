# Garad Foundation Official Logo Asset

Place the unmodified official Garad Foundation logo file here as:

`public/assets/branding/garad-foundation-logo.png` (or `.jpg`)

Then regenerate the Annual Report PDF by running:

```bash
npm run generate:reports
```

The Annual Report PDF Design System (`scripts/pdf/annualReportDesignSystem.ts`) will automatically embed the unmodified official logo in the upper-right corner of every page while strictly preserving its original aspect ratio.
